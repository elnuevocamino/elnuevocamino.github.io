**Sí, absolutamente.** Aprender a programar sigue siendo una inversión de alto valor, pero el objetivo ha cambiado: ya no se trata de *escribir* código, sino de **pensar con lógica y arquitectura**.

### 💻 El Programador como Ingeniero del Conocimiento

La IA automatiza la sintaxis y el código repetitivo, pero no puede reemplazar la **lógica de alto nivel**. Programar es una habilidad fundamental que te enseña a:

1.  **Pensamiento Lógico y Algorítmico:** Es la base para **diseñar sistemas complejos** y para saber *qué* pedirle a la IA. Sin entender la lógica, no puedes auditar ni corregir el código que la IA genera.
2.  **Arquitectura y Diseño:** El valor se traslada a la capacidad de construir la **estructura** completa de una aplicación (microservicios, *cloud*). La IA es un excelente ayudante, pero tú sigues siendo el arquitecto principal.
3.  **Habilidad de Auditoría:** Si la IA genera un error o una vulnerabilidad de seguridad, solo tú, con conocimiento de programación, puedes detectarlo y corregirlo. El **código que no se entiende no se puede gobernar**.

**En resumen:** Programar te da el **lenguaje para comunicarte con la IA** y la **capacidad para diseñar soluciones**. Es más valioso que nunca, pero ahora es una herramienta para la productividad, no el fin en sí mismo.
